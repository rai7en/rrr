Plain HTML/CSS/JS project. No build step needed.

## Run
Open `index.html` in a browser (or use Live Server in your editor).

- `index.html` - all screens (login, ribbon, welcome, video, letter, final)
- `style.css` - theme and animations
- `script.js` - login check, ribbon untie, video playback
